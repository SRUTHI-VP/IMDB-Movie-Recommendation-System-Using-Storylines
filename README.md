# IMDb Movie Recommender System

## Overview
A content based recommender system using IMDb storylines. The project scrapes movie data, preprocesses text with natural language processing, and applies TF IDF vectorization with cosine similarity to suggest movies with similar plots.

## Features
- Automated data scraping with Selenium
- Text cleaning and preprocessing
- TF IDF vectorization for storyline representation
- Cosine similarity for ranking movie similarity
- Simple recommendation function for related movies

## Usage
Clone the repository, install dependencies from requirements.txt, and run the scripts to scrape, preprocess, and analyze movie data.
